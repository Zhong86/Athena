# Athena
A personal study agent that understands the student's current topics and help them improve. A project created for the AI Hackfest Hackathon by IDwebhost.
## Features
### Up-to-Date Materials
Knowledge sync with student's Google Drive files (recommended to be used with institution email). The files and notes are divided into Topics instead of just 1 file. This helps with better correlation and gives the agent an idea on what the student is currently learning. 
### Goal and Roadmap
Help students achieve a specific goal; can be something simple like "Passing this quiz" or something more grand like "Getting into this internship". The plan relies on both student's materials but also external resources if the student is not currently learning the topic required to achieve that goal. The Goal can be set a deadline as well so student can be notified on the deadline of each Roadmap.
### Restricted Resources
The external resources to help student can be restricted so students can choose their prefered websites for sources of knowledge. This way knowledge on materials won't be corrupted with untrusted websites.
